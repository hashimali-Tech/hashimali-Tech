## 🚀 About Me

I'm a **BSIT student and aspiring Full-Stack Developer** with a strong interest in building modern, scalable, and user-friendly web applications.

My core focus is the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. I enjoy working across the entire development lifecycle—from designing responsive interfaces and building REST APIs to integrating databases and exploring AI-powered features.

Alongside web development, I am actively learning **Python, Machine Learning, and Data Analysis**, aiming to bridge the gap between traditional full-stack engineering and intelligent, data-driven applications.

- 💻 Currently building full-stack applications with **React.js** and **Node.js**.
- ⚙️ Designing RESTful APIs and working with **MongoDB** for data persistence.
- 🤖 Exploring **AI integration**, **Machine Learning fundamentals**, and **Deep Learning** through hands-on Python practice.
- 🎨 Passionate about clean UI/UX, responsive design, and writing maintainable code.
- 🌱 Continuously improving my engineering skills through real projects and structured practice.
- 📂 All my learning artifacts, project files, and practice notebooks are organized and pushed to GitHub.
